AMD Adrenalin Update 26.2.1

11‑02‑2026

AMD Software: Adrenalin Edition 26.2.1

New update available since February 11, 2026.

🎯 New Features

  • Continuous optimizations for stability and performance

🎮 New Game Support

  • Yakuza Kiwami 3 & Dark Ties
  • Nioh 3

🔧 Fixed Issues

  • Corrupted clouds in Arc Raiders (RX 9000)
  • Intermittent crash in The Finals with ray tracing enabled (RX 7000)

⚠️ Known Issues

  • Intermittent crash in Cyberpunk 2077 with Path Tracing enabled
  • Intermittent crash in Battlefield™ 6 on Ryzen AI 9 HX 370
  • Intermittent crash in Roblox Player when task switching (RX 7000)
  • Texture flickering or corruption in Battlefield™ 6 with Record and Stream
  • FSR Upscaling and Frame Generation may show as inactive in Yakuza Kiwami 3 & Dark Ties and Call of Duty®: Black Ops 7 (RX 9000)
  • AMD Install Manager may fail to install optional drivers (workaround: download from the official page)

📦 GPU Compatibility

Desktop cards:

  • AMD Radeon™ RX 9070 / 9060 Series
  • AMD Radeon™ AI PRO R9700
  • AMD Radeon™ AI PRO R9700S
  • AMD Radeon™ AI PRO R9600D
  • AMD Radeon™ RX 7900/7800/7700/7650/7600 Series
  • AMD Radeon™ RX 6900/6800/6700/6600/6500/6400 Series
  • AMD Radeon™ RX 5700/5600/5500/5300 Series

Laptop cards:

  • AMD Radeon™ RX 7900M/7800M/7600M Series
  • AMD Radeon™ RX 6800M/6700M/6600M/6500M/6300M Series
  • AMD Radeon™ RX 5700M/5600M/5500M/5300M Series

🔧 Supported Processors

Desktop:

  • AMD Ryzen™ Processors with Radeon™ Graphics
  • AMD Ryzen™ PRO Processors
  • AMD Athlon™ Processors with Radeon™ Graphics
  • AMD Athlon™ PRO Processors

Mobile:

  • AMD Ryzen™ AI Series Processors with Radeon™ Graphics
  • AMD Ryzen™ Processors with Radeon™ Graphics
  • AMD Ryzen™ PRO Processors
  • AMD Athlon™ Processors with Radeon™ Graphics
  • AMD Athlon™ PRO Processors

💻 Supported Operating Systems

  • Windows® 11 version 21H2 and later
  • Windows® 10 64-bit version 21H2 and later

📥 Installation

For RDNA GPU users, AMD Software: Adrenalin Edition 26.2.1 can be downloaded from AMD’s official website or via Auto-detect and Install.

Tip: use AMD Cleanup Utility when upgrading from an older version for a clean install.

Important: this driver does not work on Apple Boot Camp systems.
